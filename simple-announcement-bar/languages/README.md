# Translations

Simple Announcement Bar is translation ready and uses the text domain `simple-announcement-bar`.

To translate the plugin:

1. Create a .pot file with WP-CLI: `wp i18n make-pot . languages/simple-announcement-bar.pot`
2. Open the .pot file in Poedit and create a .po file for your language.
3. Save the generated .mo file in this folder, for example `simple-announcement-bar-de_DE.mo`.

Once the plugin is listed on WordPress.org it can also be translated at translate.wordpress.org.
