# Simple Announcement Bar

Shows a dismissible announcement bar at the top of your site.

## Requirements

- WordPress 6.5 or newer
- PHP 7.4 or newer

## Installation

1. Upload the plugin folder to wp-content/plugins and activate it.
2. Go to Settings > Simple Announcement Bar to configure it.

## Development

Run composer install, then composer lint to check the code against the WordPress coding standards and composer fix to fix what can be fixed automatically.
