== Description ==

Shows a dismissible announcement bar at the top of your site.

== Installation ==

1. Upload the plugin folder to the /wp-content/plugins/ directory, or install it from the Plugins screen.
2. Activate the plugin through the Plugins screen.
3. Go to Settings > Simple Announcement Bar to configure it.

== Frequently Asked Questions ==

= How do I configure the plugin? =

Go to Settings > Simple Announcement Bar in the WordPress admin.
